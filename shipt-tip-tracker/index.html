How to Use with Shipt

  1. After each delivery, log the address and tip here
  2. When a new order pops up, search the address in Lookup
  3. See instant tip history to decide if it's worth it

Importing Shipt History

Go to shipt.com → Payment History → Download CSV. Then use "Import Shipt CSV Data" above.

Tip Ratings

  • Great tipper ($10+ avg or 15%+)
  • Decent tipper ($5-10 avg)
  • Low tipper (under $5 avg)
  • No tipper ($0 history)
  • New / not enough data
